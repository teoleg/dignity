# Architecture decision records

One file per decision: `NNNN-short-title.md`, numbered in order.

Each should be short and cover: the context, the decision, and what it rules
out. Record the *why*, especially when the reason is a halachic, typographic,
or cemetery-process constraint rather than a technical one — that reasoning
is the part that gets lost.

Empty so far. The pending decisions are listed in `docs/open-questions.md` § E.
