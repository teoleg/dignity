# Samples

Drop the cemetery's real artifacts here:

- **The order sheet** that has to be filled in — especially the page with the
  Hebrew-to-numbers encoding table. This is the blocking input for the whole
  encoder.
- **A finished monument** (photo or proof) — this is what tells us the house
  style: opening abbreviation, month-name variants, honorifics, layout.

Both are read in `docs/open-questions.md` § A.

Note on privacy: if a sample contains a real family's details, that is fine
for reading the format, but say so when you add it — we should decide
deliberately whether real names live in version control, or whether we redact
and keep only the layout.
